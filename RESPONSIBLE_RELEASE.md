# Responsible release statement (draft for the paper)

All tasks are toy-scale instances generated by us (primes of 40-96 bits, 20-36-bit curves, 4-6 digit PINs,
short XOR keys). They do not target real systems, keys, or data, and solving them gives no uplift beyond standard
introductory cryptography course material. Hint text names only textbook techniques. The adversarial framing
contains stated unauthorized intent in generic terms and no real victims, targets or credentials. We release
generators, verifiers, prompts and raw model outputs to support reproducibility and defensive evaluation.
We disclosed no vulnerabilities, and we did not tune prompts to bypass any provider's safeguards.
